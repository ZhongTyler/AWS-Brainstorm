# Crazy 8s

## Contract

- Method ID: `crazy-8s`
- Category: `divergence`
- Status: `ready`
- Content version: `2`

公共约束见[方法操作约定](../OPERATING_GUIDE.md)。

## Purpose

用一轮有界快画打破第一个答案，产生八个可区分的候选片段。

## Input contract

一个明确挑战、不可改变的约束，以及纸笔/画布或文字适配的选择。

## Use when

已有第一想法但替代单薄，需要快速探索不同动作或结构。

## Avoid when

需要查明事实或细化已采用规格；无法产生差异时不靠八个标题凑数。

## Procedure

1. 固定同一挑战，把纸或画布分成八格；原版是个人在八分钟内画八个不同想法。
2. 每格表达一个可辨识的动作、结构或反馈，不把同一方案的连续八帧算八个替代。
3. 用户实际快画时才记录真实计时；Agent 不模拟八位参与者，也不伪造用时。
4. 纯文字时明确标为“八格文字适配”：每格写触发情境、行动和结果，保留原序号。
5. 完成后一起看实质差异，重复项如实标记；选择与正式采用沿用户决定。

## Output contract

C8-1～C8-8 的草图或片段、差异及待问问题；未完成格保留空缺与原因。

## Exit conditions

原版计时结束即停；文字适配一轮八格为上限。约束冲突、重复或已足够推进时可提前停，记录实际数量。

## Single-user + AI adaptation

Agent 可提出替代片段或整理用户草图；文字版保留八格意图，属于本仓适配，不声称复制了手绘和计时体验。

## Traceability

保留格号、实际作者、媒介及衍生 Idea 引用；相同格的修订仍遵守版本追加。

## Evidence boundary

Google 实践页支持个人、八格、八分钟快画。本仓文字适配和案例为自编；采用为可用操作，收益随后续反馈调整。

以下为合成行为案例，分别展示可执行路径与应拒绝的误用。

## Behavior cases

### Positive case

`CASE-C8-P01`：“让共享工具更容易归还”：八格分别探索工具轮廓槽、借用占位牌、归还托盘、借出倒计时、柜门提醒、同伴交接、近手收纳、缺件灯。展示各自改变的动作，未把八格拼成一个已采用方案。

### Negative case

`CASE-C8-N01`：把“借出→使用→归还”的八张连续流程帧称为八种方案。它只有一条方案，应回到不同归还机制；模型生成耗时不记成用户完成了八分钟练习。
