# 旧项目重做核心体验

从旧版一个可定位的片段开题。先辨认三件事：制作人现在想做什么、希望玩家经历什么、旧版的哪些部分已经承载这种体验。旧试玩证据和当时的决定按原版本解释，已确认沿用的约束继续有效。封存只确定可供回看的版本，当前想做的体验从本轮明确表达或仍适用的决定取得。

这一轮优先推进仍缺的判断。目标体验待确认时，用具体片段问玩家应当在什么时刻、因为发生了什么而感到什么。若当前体验目标已有依据，直接用旧版片段检查哪些部分承载得住、哪个缺口值得返工。进入核心机制前，在当前讨论或已有继续记录中能指出目标的依据、旧版证据及该机制要解决的承载问题即可。

同一片段可以帮助说清体验，也可以检验机制。首次展开时说明它服务哪个问题。制作人讨论了旧版某个规则、给出例子或认可封存，一律按表达的具体范围记录。
