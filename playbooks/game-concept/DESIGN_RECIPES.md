# 游戏设计操作配方

这些配方复用现有方法与本仓操作，不增加Recipe Method ID。仅实际执行正式方法时登记其ready Method ID；可以直接讨论具体局面，不为使用配方强建Run。需要事实或深度分析时按原入口查Knowledge/GameAnalysisDecision，本文可独立用于设计提案。来源见[游戏设计来源](../../docs/research/game-design-sources.md)。

## R1 · 体验承诺到具体局面

输入：已知目标、边界、已有Raw/Idea。适用：体验词无法指导设计；目标明确且只是局部实现时直接处理。

1. 用一个情境说明玩家此刻看见什么、想做什么。
2. 列可行行动与暂时未知，连接即时/延后代价、规则后果和可理解反馈。
3. 改一个条件，或比较另一个能服务同一体验的局面，说明差异与牺牲。
4. 信息足以判断方向即停；目标冲突回用户，具体参数交下游。

复用：future-backcasting、first-principles、how-might-we；GAD体验命题链提供分析线索，完整GAD诊断不复制为本配方。产物：局面、关键关系、未知及退出理由。

正例（合成）：目标是“带着收获返程的犹豫”，比较安全返回与有额外信息的绕路，并说明已有收获和危险如何可见。反例：只把界面涂红就宣称紧张；纯动作节奏也不必强行加入经济赌注。

## R2 · 同局面对照与机制减法

输入：共同起点、实际或明确假设的规则、机制计划与最强已知合法替代。适用：机制很多却看不出价值；确定性按钮修复无需整套比较。

1. 固定盘面、能力、个人与共用资源及必要随机条件；不能为新方案重抽有利题。
2. 比较使用机制、直接行动或不行动，必要时用SCAMPER拿掉、替换或反转一条关系。
3. 比较到能影响判断的共同阶段，说明节约的资源是否真的可用、是否触发新的威胁。
4. 保留机制有用、替代同样好、机制冗余的情形；决定查内容、供给还是反馈，足够推进即停。

复用：scamper、assumption-reversal；GAD同盘价值比较支持深度核查。产物：条件、代价、后继结果及最强已知替代；纸面推演不是实机或全局最优证明。

正例（合成）：推开盾手才有贯通射线；当射手已有穿透时推位不再增加价值。反例：只展示推位动画或处理数量，不比较本可直接解决的计划。

## R3 · 主题到世界规则、冲突与行动

输入：主题、玩家位置、已有世界事实与边界。适用：题材只剩名词，或设定与实际行动矛盾。氛围和创造作品可从对象、感官和表达起步，不必编角色冲突。

1. 提取主题中可辨识的对象、动词、资源和关系；可用类比或混搭借具体特质。
2. 叙事相关时连接角色欲望、约束、信息与行动代价；区分世界事实、角色相信的事和玩家所知。
3. 写一个能让玩家亲自参与的片段，检查反馈是否承接同一主题，是否容许自己的表达。
4. 形成足够的主题—行动关系即停；不在Brainstorm穷举全部对白、设定和分支状态。

复用：analogy、mashup、nm-method，GAD叙事操作可供分析；产物是关系与候选片段，不是完整叙事制作合同。

正例（合成）：修复旧物时选择保留痕迹或翻新，结果回应物主记忆。反例：主题写关怀，规则却无差别奖励损毁；先判断是否有意表达冲突，再决定改哪一层。

## R4 · 观察、假设、试探、反馈与迁移

输入：玩家需获得的一项认识、可用线索、低风险尝试与后续应用情境。适用：教程跟随成功但独立使用未知，或探索只能猜作者意图。

1. 分开指令理解、动作执行、规则理解与迁移，不用一次完成率合并。
2. 给可被发现的线索，允许形成和检验假设，失败应有可理解反馈。
3. 设计一次独立使用与必要的新情境应用；提示和无障碍辅助不同，不能随意一起撤除。
4. 有学习路径假设即可交下游验证，现成行为证据足够则复用；不把纸面设计写成玩家已学会。

复用：assumption-reversal、analogy，GAD学习检查补证据区分。产物：线索、可能解释、试探与反馈、后续应用机会。

正例（合成）：有提示时用箱子挡光；另一布局无箭头但保留可辨识光路，玩家自行选择。反例：去掉所有可读线索和操作辅助，再把失败归为玩家不会思考。

共同边界：候选、例子、实际采用、工程验证和真实体验分开。无增量可跳过，重要决定回原宿主；完整规则、状态验算、白盒与实际Play沿FromDemoToSpec/GAD等既有分工继续。
